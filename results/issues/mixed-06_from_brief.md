# Search returns no results for queries containing apostrophes

**Labels:** `bug`, `search`

## Summary
Searching for terms that include an apostrophe (such as "O'Brien") yields empty search results without any error message.

## Steps to Reproduce
1. Enter a search term containing an apostrophe (e.g., "O'Brien").
2. Execute the search.

## Expected Behavior
Search returns matching results for queries containing apostrophes.

## Actual Behavior
Search returns empty results without displaying an error message.

## Environment
- Browser: Firefox

## Additional Notes
- Frequency: always
- Assumptions: Assumed matching results exist and were expected to be returned for queries containing apostrophes.
