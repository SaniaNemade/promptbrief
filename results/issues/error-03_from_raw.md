# Error 503: Service Unavailable when clicking checkout

**Labels:** `bug`, `payments`

## Summary
User receives `Error 503: Service Unavailable` when clicking checkout with 3 items in the cart.

## Steps to Reproduce
1. Have 3 items in the cart.
2. Hit checkout.

## Expected Behavior
Navigate to the payment page.

## Actual Behavior
`Error 503: Service Unavailable` is displayed.

## Environment
- OS: Windows (laptop)
- Browser: Chrome
