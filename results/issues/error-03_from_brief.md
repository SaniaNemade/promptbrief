# Error 503 Service Unavailable when proceeding to checkout

**Labels:** `bug`, `payments`, `severity: high`

## Summary
The user encounters an `Error 503: Service Unavailable` error when attempting to proceed to checkout with three items in their cart.

## Steps to Reproduce
1. Add 3 items to the cart
2. Click checkout

## Expected Behavior
Navigate to the payment page

## Actual Behavior
Displays `Error 503: Service Unavailable`

## Environment
- OS: Windows
- Browser: Chrome
- Device: laptop
